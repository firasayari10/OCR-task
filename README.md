# React Landing Page

A beautiful, modern landing page built with React and Vite.

## Features

- 🎨 Modern and responsive design
- ⚡ Fast development with Vite
- 📱 Mobile-friendly
- 🎯 Smooth scrolling navigation
- ✨ Beautiful animations and transitions

## Getting Started

### Installation

```bash
npm install
```

### Development

Start the development server:

```bash
npm run dev
```

The app will be available at `http://localhost:5173`

### Build

Create a production build:

```bash
npm run build
```

### Preview

Preview the production build:

```bash
npm run preview
```

## Customization

You can easily customize the landing page by:

- Editing `src/components/LandingPage.jsx` for content and structure
- Modifying `src/components/LandingPage.css` for styling
- Updating colors, text, and images to match your brand

## Technologies Used

- React 18
- Vite
- CSS3 (with modern features like gradients and animations)
